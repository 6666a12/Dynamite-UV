# 账号后端（开发预览）

已接PostgreSQL真实持久化；尚未接游戏UI或公开部署。

## 当前约定

- 用户名：trim后转小写，ASCII字母/数字/下划线，3–32字符；不另设邮箱、手机号或昵称。不区分大小写，同名409。后续昵称可独立扩展。
- 密码：12–128个.NET UTF-16代码单元，不trim、不转换大小写；不强制大小写/符号组合。没有邮件/验证码验证。
- 使用ASP.NET Core Identity V3 PasswordHasher：随机盐、PBKDF2-HMAC-SHA512、210000次迭代，支持成功登录时升级旧哈希。不是自制密码算法。
- 会话：随机256bit不透明bearer，数据库只存SHA-256摘要；数据库时间计算24小时有效期，每账号最多10个有效会话。新登录清除该账号过期/多余旧会话；没有刷新令牌、自动登录或客户端秘密存储实现。
- 账号禁用后会话立即不能认证。退出只撤销当前token，不影响他人。本人接口不接受外部accountId决定身份。
- 找回密码、改密、删除账号、管理员初始化、过期会话全局清理任务尚未实现；没有默认管理员或后门。不要把此版本当正式运营服务。

## API v1

| 操作 | 路径 | 返回 |
|---|---|---|
| 注册 | POST `/api/v1/accounts/register` | JSON username/password；201账号id和规范用户名；400格式错误；409用户名不可用 |
| 登录 | POST `/api/v1/accounts/login` | JSON username/password；200 accessToken/expiresAt/account；未知用户、错密码、禁用均401 |
| 本人 | GET `/api/v1/accounts/me` | `Authorization: Bearer <token>`；200本人profile；无效/撤销/过期401 |
| 退出 | POST `/api/v1/accounts/logout` | 同上；204撤销；无效401 |

数据库未配置、未迁移、实例不匹配或不可用返回503，不能绕过检查。远程请求必须HTTPS；仅实际回环连接允许开发HTTP，不信任任意转发头。反代HTTPS接入须后续明确可信代理配置，不能直接放开X-Forwarded-For/Proto。

使用参数化SQL传入所有值；动态SQL只有受控迁移和测试生成的库名。响应no-store，不记录请求正文或Authorization。需要生产低权限数据库角色和TLS部署验收；本地开发角色为初始化管理员，不可直接用于公网服务。

频率限制目前采用有界、保守的全实例保护：业务请求120次/分钟，ready/database另有共享的独立健康预算，live豁免；注册+登录共20次/分钟，密码处理最多2个并发、无排队。账号接口十秒整体deadline传至后续数据库查询，超时释放凭据工作槽；不把该截止施加于曲库发布/传输。达到频率限制返回429。它避免不受控IP分区缓存和过量哈希，但会影响同实例其他用户；生产前仍须设计可信代理下的IP/账号限流，不能当已解决分布式撞库/DoS。

## 验证与接线边界

`python server/dev.py test`使用独立随机数据库，通过真实Kestrel HTTP验证注册、大小写冲突、无效用户名、错密码/未知用户、包含SQL语法的密码、两账号身份隔离、哈希存储、退出及撤销、过期、限流。默认仓库verify仍不依赖数据库。

发现接口在数据库迁移和实例检查ready时返回账号/曲库/本人记录能力为true；管理员本机授权与业务接口见[API说明](../API.md)。客户端未发起登录请求、未保存token、结算未上传，不改变本地游玩/成绩。
