### 屏风几何

双扇不透明屏风由左右向中间合拢，再沿原路拉开。材质复用现有 Signal Lock：
底色 `#070B16`、斜纹步距 170 / 横向倾斜 380、分片宽 116、分片色 `#101A2F`。
中缝采用三个错位段，x=922 / 960 / 998，接缝斜切 34px；不是透明擦除蒙版。
每扇平移量 `1020×(1-coverage)`，闭合时两扇严密遮住整个画面。
青色边缘为 5px 实线 + 1px 浅色内芯，外围只有很薄的辉光。闭合停顿不添加说明文字。
曲目信息和评级在全闭合后切换底层内容，屏风拉开期间只露出结算空背景。

## 客户端时间线

**600ms 合拢 → 320ms 停顿 → 480ms 拉开 → 评级先落位 → 信息依次浮现**。
完整揭晓约 **2650ms**，评级在 1400ms 开始播放既有 24fps、30 帧入场序列。
`UiMotionProfile.ResultDuration` 与 `ui-motion.md` 的 Full 结算时长已更新为 2650ms。

| 时间（相对 `ShowResults` 调用） | 画面 |
| --- | --- |
| 0–600ms | 左右屏风由外向内合拢，完全遮住游玩画面；尾音继续正常播放 |
| 600–920ms | 完全闭合停住 320ms；在遮挡下换成结算背景，不提前显示评级或成绩 |
| 920–1400ms | 屏风左右拉开，只露出结算空背景 |
| 1400–1780ms | v5 评级序列单独入场，约 1692ms 到第 8 帧命中；其它信息仍隐藏 |
| 1780–2040ms | 曲目信息、模式标记与 CLEAR 先后向上 18px 淡入 |
| 1940–2180ms | 分数与纪录信息向上 18px 淡入 |
| 2080–2420ms | 成就徽章与 Max Combo，随后判定比例条和计数依次浮现 |
| 2360–2600ms | 底部按钮最后浮现；揭晓期间点击只跳过，不穿透触发按钮 |
| 2650ms | 评级序列播完，进入低频表面电流循环；页面其它内容稳定 |

分镜 `storyboard.png` 展示五个时间点和 AP 变体。`timing-preview.mp4` 使用同一屏风
几何进行实际平移，播放真实评级 PNG 帧序列，逐组浮现 Penpot 导出的透明 UI 图层。
它是设计动效预览，非 Godot 实机；结尾停留供看清完整页面。
评级稳定态保留最后几帧的低频表面电流往返循环，约 7fps、低于入场爆发强度；Reduced/Off
仍使用静态评级。

Reduced 使用 260ms 短淡入，取消砸入、分数滚动、强爆闪与外部电弧；
Off 直接显示稳定页，遮住 Gameplay，避免短暂透层。
音乐尾音不因屏风动作主动截断；离开/重开由既有导航停止播放。
**真实触发边界**：当前 `GameplayMain` 在谱末后约 2 秒或音频自然结束时调用 `ShowResults`。
上述揭晓时钟从该调用开始，不表示最后一个判定瞬间启动。若以后要求判定结束即开始，需单独改代码与回归，不能只改文档。
音效资产与混音仍未在本方案完成。

## 示例数据与状态规则

- 主板：PREFECT 920、GREAT 80、GOOD 0、MISS 0，总判定 1000；
  `(920×100 + 80×70) / (1000×100) = 97.60%`，得分 976,000，评级 S，
  Max Combo 1000，FULL COMBO。旧纪录 962,500，增量 +13,500。
- AP 板：PREFECT 1000，其余 0；CLEAR 100.00%，1,000,000 分，评级 Ω，
  ALL PREFECT。旧纪录 976,800，增量 +23,200。
- `PREFECT` 沿用项目既有拼写。判定配色沿用旧结算：青/金/绿/灰紫。
- AP 与 FC 共用一个徽章位，AP 优先；普通完成保留成绩区对齐，隐藏成就徽章，不显示假 FC。
- 只有破纪录才显示 NEW RECORD 与正增量；非纪录可显示既有 BEST，不强制增加警示颜色。
- AUTO 必须显示「AUTO · 不计成绩」，不写成绩，也不显示 NEW RECORD；本组画板展示手动游玩。
- 当前 BLEED 机制尚为预留。画板里的模式标签只反映所选配置，不代表新增机制已经实现。
- 早/晚偏移直方图留待详细统计设计，本轮主屏不加入。

## 构建与检查

驱动 `.tmp/penpot_result_v2.py` 复用既有 MCP 连接与文字两阶段对齐，优先按已保存的
六个画板 id 原位改名与重建，再按精确名字兜底。每次写入前检查文件名、Game UI 页、
原坐标与目标板身份；上传媒体先于画板清理。
可恢复的六板构建 JS、helpers 与 fixup 保存在 `design/result-v2/source/`，不含凭据。

设计重建时必须检查导出尺寸、文字边界、示例数值、零判定条宽，以及非目标画板结构清单不变；历史检查记录不代表本次重跑。
客户端实现位于 `client/scripts/ui/ResultScreen.cs`、`ResultShutter.cs`、
`ResultRevealTimeline.cs` 与 `ResultGradeArt.cs`。`GameplayMain` 仍负责计算/保存成绩，
并在保存前读取旧最佳分数用于 NEW RECORD 增量。新 UI 不改变 legacy/v2 成绩身份。

运行时资产为 `client/assets/results/`，生成器
`tools/grade-assets/build_runtime_results.py` 将每级 30 帧无损拼为 3072×2560 图集，
每帧 512×512、6 列×5 行，逐帧对比 RGBA。只异步加载本次评级的一张动画图集；
加载未完成时停在不透明闭合阶段，完成后仍完整播放拉开动作。动画不可用时回退静态评级。
静态图与动画最后一帧一致；Full 稳定态约 7fps 往返图集末尾帧保留表面电流，不再更新其他信息；Reduced/Off 静态。

Full 入场期间单击/触摸或 Enter/Space/Escape 可跳过；当前事件被消费，另有 120ms
防穿透间隔。按钮入场时不接收输入。返回、下一首、再来一次继续调用既有导航。
Reduced/Off 只加载静态评级；音乐尾音不中断，离开或重开时按既有导航停止播放。
Public export 明确列入 20 个 PNG/SVG 资源；来源与哈希记录在
`release/asset-provenance.json`，不包括设计预览、Blender 工程或原版参考资源。

当前回归入口：`ResultRevealTests` 已注册在 core-tests，覆盖开合顺序、慢加载闭合等待、跳过与 Reduced/Off；
图集生成器含逐帧 RGBA 校验。复验流程见 [当前交接](<handoff.md>)。
历史构建/测试/无界面导入记录保留在归档；本次整理没有重跑，也没有启动游戏替用户目测。
