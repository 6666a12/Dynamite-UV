## 保持的边界

- `EditorStagePlacement` 拥有舞台时间反查、单锚吸附增量与固定逻辑边调宽；Shell 仍拥有精确文档、命令与组合撤销，Godot 仍拥有输入和投影。
- Scroll 是非积分视觉模型，降速曲线可能多解，Hold 跳变也可能没有精确逆。当前采用从当前时间扩展得到的区间内二分选择根/跳变边界；不声称所有非单调曲线有唯一逆。
- 路径整体移动沿用现有命令语义：时间平移覆盖节点，中心/宽度编辑作用于头部；ghost 必须匹配此语义，不在本轮擅自重写路径空间移动规则。
- resize 保持**逻辑**对边。由于可见宽度有 0.95 等视觉缩放，屏幕可见对边与逻辑对边不是同一概念；预览按最终几何重投影。
- Timing 现有合法 double 值可安全加载，未改数值的 Apply 保持原值；新值输入仍受 NumericUpDown 的 decimal 表示能力限制。
