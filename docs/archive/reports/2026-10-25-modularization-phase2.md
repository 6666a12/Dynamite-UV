## 已落地的对象边界

| 对象 | 状态与职责 | 与调用方的联系 |
| --- | --- | --- |
| `GameplayNoteRenderer` | 音符、连接段、残影、失败 Hold 退场、Mixer 接收头的创建/更新/归还 | 输入谱面只读索引、设置及持续状态值快照；接收判定结果，不持有 JudgeEngine、JudgeUnit 或场景对象 |
| `GameplayEffects` | 命中与持续特效池、最老对象抢占、粒子停止/排空/回收 | 只接收路径、接触状态、颜色/位置/强度，不修改判定状态 |
| `GameplayRenderGeometry` | 既有渲染坐标换算 | 数值仍来自 GameplayStageGeometry；镜像仍走原 GameplayMirror 适配，未改公式 |
| `EditorDocumentSession` | 当前文档、首次保存资源、打开/新建/新增差分/保存/另存为 | 返回文档或类型化保存结果；页面处理对话框、文字、刷新与错误显示 |
| `SongBrowseState` | 页面本地选中包/难度、过滤结果、身份恢复 | 不加载音频、不提交 GameSession；过滤先算可见集合，再由页面按原顺序收起旧卡并选择替代项 |
| `CanvasEditGesture` | 已有对象拖动的原始值、开始阈值、提交/取消、一次性命令 | 屏幕距离和预览几何仍由画布计算；最终命令进入原 CanvasAuthoringController |

GameplayMain 分部类总量由 **2859 → 1823 行**（含注释/空行/内部类）。持续判定状态已不含
NoteView、ContactEffect 或 ContactParticles。独立渲染器三个文件合计 762 行，特效池另有独立对象；
新增文件长度不作为解耦完成依据，实际边界由状态所有权和输入输出约束。

`AuthoringCanvas` 的新建 Tap/Hold 放置、框选、命中测试和拖动预览公式仍保留。
本轮抽取的是已有对象编辑手势的提交/取消过程，没有把所有画布交互一次性重写成新状态机。
`StandaloneEditorMain` 仍负责 UI 流程，文档和首次保存资源则只有 session 一处拥有。
首页/页面对 GameSession 的其他依赖和 editor 的共享视觉源码链接仍在，未宣称全部耦合消除。

## 必须注意的行为修正

**修复：未保存的内存草稿新增难度后，首次保存不再丢失外部资源。**

旧 `ConfirmCreate` 的 AddDifficulty 分支会先 `_draft = null`。若包尚未落盘，新增难度成功后，
SAVE 因缺少草稿中的外部音频/封面信息失败；即使新增差分随后失败，也可能已清掉原草稿资源。
session 现在在新增难度时保留原 Draft，仅在成功打开其他包或首次保存成功后清除。
回归实际创建了含音频、封面、两个非空差分的包并重新严格打开，验证成功与失败路径。

此外没有有意修改判定窗口、计分/成绩身份、几何数值、对象池容量/抢占顺序、按键阈值、
同帧输入顺序或保存格式。新增难度的初始 150 BPM/0 偏移仍沿用原行为。

已有写包器的“发布完成但清理临时目录失败”仍可能抛异常；本轮保留失败时 dirty 的处理，
只纠正了“所有异常都说明磁盘未发布”的错误代码注释，未改写该异常语义。

## 自动验证范围

1. `python -B tools/verify.py --no-restore`：结构门禁、两端构建、核心与编辑器回归、37 项发布测试、diff 检查。
2. 新增核心回归：选曲标题/曲师/谱师过滤、精确身份恢复、难度循环与清空。
3. 新增编辑器回归：打开/新建失败保留当前文档、草稿首次保存、多个差分、保存失败/另存为、
   3px 阈值、精确分数时间、无变化不写命令、取消、单次 undo、路径头与节点编辑。
4. 拆分前后实际 Godot 无窗口对比：使用本地隔离探针和合成谱面，不读取/写入玩家设置与成绩。

无窗口对比采用固定 60fps，8 个场景各 480 帧，共 **3840 个模拟帧、7680 条记录逐字节一致**：

| 谱面 | 输入 | 镜像 | 判定/分数轨迹 | 节点状态轨迹 |
| --- | --- | --- | --- | --- |
| golden 派生合成谱 | Auto | 关/开 | 各 480 帧相同 | 各 480 帧相同 |
| golden 派生合成谱 | 确定性手动输入 | 关/开 | 各 480 帧相同 | 各 480 帧相同 |
| 高密度派生合成谱 | Auto | 关/开 | 各 480 帧相同 | 各 480 帧相同 |
| 高密度派生合成谱 | 确定性手动输入 | 关/开 | 各 480 帧相同 | 各 480 帧相同 |

高密度谱加入 40 个同刻 Tap、40 个重叠 Hold 与 40 个重叠 Mixer，覆盖有限池的抢占。
节点记录包含层级顺序、音符位置/状态/透明度、连接段顶点/颜色、特效节点位置/显隐。
手动序列包含短点、拖动、松手和失焦清理。八组在基线与新实现上均无运行错误。
这不是渲染像素比较，也不是 GPU 粒子外观、真机触控、音频或性能验收；暂停菜单动画和完整 UI 操作链未在此对比中覆盖。

本地证据在 `.tmp/modularize2/`：`baseline.log`、`final-verification.log`、`before/after-*.trace.jsonl`、
`before/after-*.nodes.jsonl` 及 `equivalence-summary.json`（逐组 SHA-256）。临时源码快照用于对比，未改变 Git 基线。
基线首次发布测试曾扫描到临时文档快照，已将快照改为非源码扩展名；没有修改发布测试的白名单来放过该失败。
探针首次启动受 sandbox 的 user://logs 写权限阻止，获授权后运行；后续通过结果来自正常完成的无窗口运行。

客户端构建 0 warning / 0 error；编辑器构建 0 error，保留本机 NuGet 漏洞索引不可达的 NU1900 环境警告。
本轮没有打开可见游戏窗口、导出 APK 或提交 Git。
