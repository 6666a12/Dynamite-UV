# 编辑器 UI 分层回归清单

这份清单持续维护覆盖层级，具体执行日期/结果在 [验证记录](verification.md)。用户2026-11-09已确认最近一批制谱器功能整体满意、可收尾；下表“未穷尽”仅指专项覆盖，不撤回整体确认。

| 层级 | 交互／状态转换 | 当前覆盖 |
| --- | --- | --- |
| 原生宿主 | 启动隐藏、嵌入、浮动、关闭还原、重复还原、IPC 连续 | 既有真实窗口回归 |
| Dock 工具面板 | tools/timing/properties 收起、预览、收回、再展开、固定、关闭恢复 | 无窗口生命周期回归通过；真实鼠标两轮收起／展开／固定通过，布局无舞台重叠 |
| 动态面板 | 添加、关闭后重新添加、重复恢复不复制对象 | 无窗口生命周期回归通过 |
| 顶层菜单 | File/Edit 打开与关闭，Help 打开与 Escape 退出 | 无窗口鼠标／键盘通过；真实窗口鼠标打开菜单、打开／关闭 Help 通过 |
| 工具按钮 | PLACE/PATH/PAN/SELECT 鼠标切换 | 无窗口鼠标通过 |
| 创建弹窗 | 无效表单保持打开并报错、自定义难度字段显隐、取消无结果 | 无窗口输入／控件状态回归通过 |
| 属性／时序面板 | 精确几何、曲线、类型、速度、BPM/Scroll、删除／撤销 | 既有命令和控件事件回归；不能视为全部实际点击覆盖 |
| 编辑舞台 | 三轨放置、选择、拖动、调宽、路径、PAN、撤销；当前轨道跨屏时间范围框选 | 既有真实窗口和 Godot 无窗口输入回归；框选新增播放推进/回退/已判定父 Note 保留，真实按住鼠标播放跨屏与删除/撤销，执行记录见 verification |
| 任务栏恢复 | popup owner 清理、顶层激活与子窗口键盘焦点分离 | 2026-11-08 用户确认修复；不以旧强制置前测试代替此确认，不外推所有浮动/DPI 组合 |
| 文件／差分 | 创建、打开、保存、另存、复制／删除／重排 | 既有临时包集成回归；系统文件选择器尚未逐路径覆盖 |
| 焦点 | 文本输入期间快捷键隔离、弹出菜单与原生子窗口焦点交接 | 需要继续专项，不宣称完整覆盖 |
| 环境变化 | DPI、多屏、窗口最小尺寸、所有浮动工具组合、布局重启恢复 | 未穷尽；布局持久化本来尚未实现 |

## 维护边界

- 自动回归不能代替全部设备/窗口组合，用户整体确认也不自动补齐未测平台。
- 已完成的实现流水见 [历史实施切片](archive/reports/2026-11-07-editor-ui-implementation.md)。
- Auto 预览已接游戏共用视觉；`--verify-auto` 验证对象状态，不是 GPU 像素、听感或所有真实窗口输入。
