# DynaMaker UV：暂不实现的提案

**2026-11-26 最新决定：内置音频分析台和制谱助手（Agent）均暂不实现、未排期，从当前开发计划移除。** 目前预期使用价值有限，开发先转向其他需求。旧的「先做音频分析，再做 Agent」顺序不再生效；两项都不启动原型、界面、依赖接入或专用架构工作。若以后有反复出现的具体痛点，再单独评估，不自动恢复旧方案。

现有录音预览、手动对轨和[导入 BPM](<dyna-maker-uv.md#导入-bpm-与音频对轨>)不受影响。仍不计划公开第三方插件接口。

## 历史方案留档：内置离线音频分析

以下是此前讨论的设计，**仅供追溯，不是待办、实现规格或验收安排**。当时另有只读 Agent 设想：读取谱面事实和可用的音频分析结果，给带小节位置和依据的建议。

建议从**当前差分实际使用的录音**出发：它可能是谱包默认录音、差分单独录音，也可能是尚未保存的替换。工具标明正在分析哪一份，不能只按包名或差分名猜。已有[导入 BPM](<dyna-maker-uv.md#导入-bpm-与音频对轨>)读取 `.mc` / `.osu` 的现成时间点；新工具从音频估计候选。两条路并存。

### 首版建议范围

- **波形与定位。** 一个可开关、可停靠的「音频分析」面板，含全曲缩略波形与可缩放细览。显示播放头、当前谱面拍线和可开关的起音标记。点击波形只定位现有播放头，不选 Note、不落点、不改变吸附。已有八小节制谱底栏继续保留；先不把整套分析显示塞进底栏。
- **起音候选。** 标记声音突然出现或变化的时刻，例如底鼓、军鼓、拨弦或人声辅音。提供少量强弱筛选，标记是听辨线索，不是拍线、分轨结果或自动制谱点。
- **BPM 和拍线预览。** 列出少量速度候选，提示半速/倍速歧义；例如 60/120/240 BPM。允许手输 BPM。把候选拍线与现有谱面网格分开显示，方便在曲首、曲中和曲尾比较。机器分高低只表示证据强弱，不显示未校准的准确率百分比；弱节奏可明确报告「无法可靠估计」。曲首第一个起音不等于第 1 拍，也不等于小节 0。由人点选波形或手填时间，明确指定「这个时刻是小节 0」。
- **显式应用。** 只看分析、切候选或拖动候选拍线都不改谱。首版只提供「仅应用小节 0 偏移（保留 BPM 表）」及「以所选恒定 BPM 替换当前差分的整张 BPM 表，并应用确认过的偏移」。应用前展示旧值、新值和影响；已有多段 BPM 或已放音符时明确提示。复用现有 [BPM/偏移文档命令](<../tools/chart-editor-core/Commands/ReplaceBpmTimelineCommand.cs>)，一次撤销恢复对轨，显式保存才写盘；不重排 Note 的小节坐标、不改其他差分。若检测到长期漂移或多种速度证据，提示按段人工核对，不自动拼变速表。

段落自动命名、自动识别小节重音、自动变速写入、自动落 Note、频谱编辑和通用数字音频工作站功能不列为首版验收要求。先把恒速曲的辅助对轨和复杂曲的安全退路做好，不以自动识别所有歌曲为完成标准。

### 当时设想的实现顺序

1. **音频读取与波形闭环。** 后台读取播放器实际使用的本地源，按块生成逐级缩略波形，不在 UI 线程或 Godot 帧循环解码。首版目标覆盖现有 WAV、MP3、Ogg Vorbis、FLAC；先用 WAV 验证时间轴，再对其余格式核对分析和舞台的开头、曲中、曲尾。选择解码方案前验证格式、授权、打包、可取消及压缩编码的起始时间一致性。推荐正式版无需用户装 FFmpeg 或 Python，不改变现有播放实现；现有 Godot 播放适配不是 Shell 可直接复用的流式分析解码器。
2. **候选计算。** 通过短窗口的信号变化找起音，再依据多次重复的节奏估计 BPM 和拍线相位；对比不同歌曲位置，不因单个大峰值推断第一拍。分析结果按录音秒数存储，显示时用当前差分的 BPM/偏移换算。改 BPM 或偏移只重画对应关系，不重扫音频；同字节录音可复用分析，不共用差分对轨。先实现会话内有界复用，跨重启磁盘缓存按实测需要决定；缓存如落盘只存本机用户目录，不随谱包发布。
3. **面板、确认和应用。** Shell 接入现有播放/定位，管理后台任务、进度和取消；纯分析及候选数据独立可测，文档核心仍负责对轨提交与撤销。换包、换差分或替换录音后，旧任务不能覆盖当前结果；应用前再次确认目标差分、录音及预览依赖的对轨没有过期。音频不上传，不修改原录音，不新增谱面字段或分析 sidecar，不进入游戏 APK 或服务端。

### 当时设想的验收条件

- 合成有真值的录音：恒速与前导静音、不同起拍、半/倍速、静音或弱节奏、中途变速。检查恒速 BPM 候选、手设锚点后首/中/尾对齐、压缩格式时间线，以及弱证据和变速没有被伪装成可直接采用的结论。
- 文档与交互：浏览、取消、失败均不改谱；候选过期不能应用；已放音符需要提示；显式应用只改当前差分的对轨、一次可撤销。快速切换音频、同路径换内容、长录音、取消解码纳入回归。
- Windows 用原创或有授权的恒速/复杂实际曲目试用，核对波形定位、播放同步、改谱时响应和短/长曲资源占用；在未安装外部音频工具的候选包环境复核四种格式。记录误差、耗时和局限；与用户确认首版是否满足实际对轨工作，再判定阶段一完成。自动回归通过不能代替真实听感和窗口试用。
