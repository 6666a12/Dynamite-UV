# 三轨游玩渲染性能复验

目标是让通常的 Dynamix 三轨谱稳定在设备实际刷新率，不能拿 4K mania 比赛压力段给普通演出定位。这里的吞吐和帧间隔是 Godot 主循环的量，不是实际显示器帧达成数。[此前 Twin Bloom 的机制对照](<storyboard-high-refresh.md#L5-L18>)保留作压力参考。

## 改动与回退边界

| 路径 | 状态 | 行为边界 |
| --- | --- | --- |
| [投影公共输入](<../presentation/game/GameplayNoteRenderer.Projection.cs>)和 [Note 材质](<../presentation/game/NoteView.cs>) | 默认启用 | 相同时间、Bar 与 timing offset 复用原 BPM/Scroll 算式的公共输入；不重排运算、不改变判定用时间。仅材质参数确实改变时上传；入池重置后首次完整上传。仍支持断触重接、尺寸与亮度差。验证 `DUV_VERIFY_VISUAL_INPUTS=0` 保留整套原提交。 |
| [Hold/Mixer 连段](<../presentation/game/GameplayNoteRenderer.cs>) | 验证环境 `DUV_VERIFY_RETAIN_LINKS=1` | 原 `Polygon2D` 和描边原序，只在常规同轨、同流速倍率、未过线的形状可用**同一个位移精确恢复两个原端点**时复用坐标；裁切、提前锚定、失败淡出、阶跃退化、不能精确还原或池复用回原来写点。不改持续接触亮度和物理时间，也未降低动画帧数。颜色变化仍走原路径，跳过点上传不等于不重绘。 |
| [默认背景](<../presentation/game/GameplayBackdrop.cs>) | 验证环境 `DUV_STORYBOARD_BACKDROP=cache`，`flat` 是可见内容不同的对照 | 根窗口 SDR、匹配物理像素的离屏纹理只画一次，继续使用原 shader、保持原图层和父级调制；改变尺寸先回退原 shader。运行条件不合适也回退，不动原来的透明演出／Note／HUD。1440p 测试实际缓存 2560×1494，包含顶部填充，单 RGBA8 颜色面约 14.59 MiB（不含驱动额外分配）。 |

基础性能场景是受控的《MVURBD [Tech]》三轨实谱（2,146 运行时 Note、2,130 判定单位），5–21 秒，真实音频、Auto、1.4× 落速、关闭 Storyboard，Windows Vulkan Forward Mobile Debug，真实 2560×1440 全屏、不限帧、关闭 VSync、Synchronous/safe 渲染模式。临时提交 `5c4562a` 在改动前连续 3 次的中位数为 548.12 FPS，P95/P99 **2.925/3.675 ms**。这条数据不与不同时间跑的优化数据直接相减；后续以同一编译版本、交错 A/B 为准。

## 三轮交错 A/B

各数值为三轮统计量的中位数。15 个进程使用同一构建和同一谱／Digest，表中的帧间隔与 GPU 采样不是可相加的各阶段时间。

| 仅变更一项 | 吞吐 FPS | 帧间隔 P95 / P99 | Note 阶段 P95 | viewport GPU P95 |
| --- | ---: | ---: | ---: | ---: |
| 始终重交材质、重新求投影 | 587.81 | 2.417 / 2.978 ms | 0.098 ms | 0.353 ms |
| 当前默认：去重材质和投影、程序背景 | 597.38 | 2.393 / 2.933 ms | 0.057 ms | 0.345 ms |
| 在默认上启用保留连段 | 606.18 | 2.353 / 2.882 ms | 0.062 ms | 0.346 ms |
| 在默认上用纯色背景（非等视觉） | 606.42 | 2.352 / 2.908 ms | 0.061 ms | 0.222 ms |
| 在默认上用一帧背景缓存 | 591.32 | 2.396 / 2.963 ms | 0.059 ms | 0.228 ms |

- 投影及参数去重减少约 **42%** 的 Note 阶段 P95（绝对 **0.041 ms**）。整体帧尾改善很小。
- 连段试验在本次运行累计跳过约 **57%** 几何提交，但整体 P95 的差距只有 **0.04 ms**；不因一个样本就默认开启。
- 两种背景隔离都证实背景计算影响 GPU（缓存节省约 **0.12 ms**），但当前 RTX 没换来更好的整帧 P95，还占了额外颜色面，保持 opt-in。真机上可能不同，未测试。

## 行为对照

- 同一《MVURBD》固定 60 Hz 逻辑时钟下，旧提交、去重和保留连段的逐帧判定、计分、活动 Note 投影轨迹逐字节一致。隔离同帧随机光效后，真实谱的本体和连段采样像素一致；合成 Auto 曲线谱隔离效果后的 17 帧，单通道最大 1/255。全场 Auto 截图仍可能出现局部效果差异，未拿它判几何回归。固定时钟用于比对行为，不用于测帧率。
- 独立三轨合成谱覆盖 Hold/Mixer、曲线、阶跃和逐 Note 变速。另以触点注入真实游戏：中轨 Hold 在 1.783 s 提前 Perfect 并锚定、2.000 s 断触下穿、2.100 s 在宽限内回到判定线，第二次释放后永久失败。两路径完整 206 帧轨迹一致，16 个画面采样中最大通道差 1/255。
- 关闭其它舞台层，1440p 与 1370×770 物理内容视口的背景均为常态逐像素一致；部分父级透明与染色情况下，每通道最大差 1/255。测试的缓存路径有实际纹理，没有偷偷回落。尚未覆盖 Android/iPad GPU、设备内存压力或呈现帧率，也未承诺 HDR／其它渲染器相同。

复跑：用 [Windows 基准脚本](<../tools/storyboard-demo/profile_windows.py>)，选择 `--case legacy-inputs --case off --case retained-links --case flat-stage --case cached-stage`。`off` 是当前默认材质与投影；后 3 组各只更改一个因素。验证结果核对 chart/ruleset/Digest、实际窗口与 framebuffer、缓存就绪和确有连段复用。窗口条件、媒体内容和发行级别不变。仅本地开发验证，未改公开素材范围。
