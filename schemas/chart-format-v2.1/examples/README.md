# 用 Curve Study 试一条回弹曲线

在制谱器里打开 [mixed-pack](mixed-pack/) **目录**，然后在顶部的差分列表里选 `rebound`。如果拿到的是 ZIP，请先解压再选包含 [meta.json](mixed-pack/meta.json) 的那层目录。示例用两秒静音，不需要另找音乐。

1. 在 TIMING 里选小节 0 的 Scroll 事件，查看「自定义」。公式是 `1 - (1 - t)^1.5 * cos(3*pi*t)`：先超过终点，再弹回来。「过冲」提示可以保留，不会截掉这段曲线。
2. 选左侧 Mixer 的头。它使用同一条公式移动；第一个真实节点往尾点走的下一段则是 `t^1.5`。细分出来的折点不是额外判定点。正面的 Hold 演示 `t*t*(3-2*t)`。
3. 想试写盘保护，可以把公式暂时改成 `t+1`。起点不再是 0，应用会被拒绝；按保存也不会把原谱覆盖。点「放弃这条公式草稿」可回到原式。要保留自己的实验，请用另存为。

同包的 `baseline` 是普通 2.0 差分，仍使用 2.0 规则和成绩摘要；但**整个示例包的包头是 2.1**，旧游戏和旧制谱器不能打开。格式、函数和精度说明见 [v2.1 合同](../../../docs/chart-format-v2.1.md)。
